3. GROUP SCHEDULE
The notification system uses the same Group rotation logic already used by
the Demografi sheet:
- 4 groups
- Pagi / Siang / Malam / Off
- anchored to 2026-09-08
This keeps notifications and Demografi consistent.

4. NOTIFICATION LOGIC
- Supervisor receives the notification queue only when the current clock is
  inside the SHIFT assigned in TATA CARA.
- Superintendent behaves the same way.
- Current operational date is used; 00:00-06:59 belongs to the previous
  day's Malam shift.
- The expected Group is calculated from the same rotation used by Demografi.
- If a checklist is waiting for the logged-in role, it becomes actionable
  (red bell count).
- If it is still Draft / waiting for another stage / not yet filled, it is
  shown as awareness information.
- If another Group filled it, the notification shows a Group mismatch.
- Clicking an actionable notification opens the exact checklist/date/shift.
